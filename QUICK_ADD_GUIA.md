# ⚡ Quick Add - Guia de Uso Rápido

## 🎯 O que é o Quick Add?

Registro Rápido que permite anotar suas atividades **instantaneamente**, sem precisar preencher formulários completos.

### Por que usar?
- ✅ **Anote no momento** - Não espere até sexta-feira
- ✅ **Zero fricção** - Um campo só, super rápido
- ✅ **Nunca esqueça** - Registre quando acontece
- ✅ **Converta depois** - Complete os detalhes quando tiver tempo

---

## 🚀 Como usar (3 formas)

### 1️⃣ **Botão Flutuante** (Mais fácil)
```
Olhe no canto inferior direito da tela
           ↓
    ┌─────────┐
    │    ⚡    │  ← Clique aqui!
    │   Add   │
    └─────────┘
```

### 2️⃣ **Atalho de Teclado** (Mais rápido)
```
Pressione: Alt + Q
```

### 3️⃣ **Mobile/Touch**
```
Toque no botão laranja flutuante
```

## 🎬 Fluxo de uso típico:

### **Segunda-feira, 10h:**
```
1. Acabei reunião com cliente
2. Pressiono Alt+Q
3. Escrevo: "Reunião Tax One SAP - definimos prazo para 15/08"
4. Clico "Salvar Rápido"
5. Continuo trabalhando
```

### **Segunda-feira, 14h:**
```
1. Terminei uma documentação
2. Pressiono Alt+Q
3. Escrevo: "Documentei processo de validação CFOP no Confluence"
4. Salvo
```

### **Sexta-feira, 16h:**
```
1. Hora de fazer registro completo
2. Vou em "Registro Semanal"
3. Vejo minhas 5 notas rápidas da semana
4. Clico "📋 Converter em Registro" em cada uma
5. Todas as notas vão para o campo "Atividades da Semana"
6. Completo os outros campos (conquistas, desafios, etc.)
7. Salvo o registro completo
```

## ❓ FAQ

### P: As notas são salvas automaticamente?
**R:** ✅ SIM! Salvam no localStorage automaticamente ao clicar "Salvar Rápido".

### P: Se eu fechar o navegador, perco as notas?
**R:** ❌ NÃO! Ficam salvas até você deletar ou converter.

### P: Quantas notas posso ter?
**R:** Sistema guarda últimas 50. Mais antigas são removidas automaticamente.

### P: Posso editar uma nota depois?
**R:** ❌ Não diretamente. Mas você pode:
1. Converter para registro semanal
2. Editar no campo "Atividades da Semana"
3. Ou deletar e criar nova

### P: O que acontece depois de converter?
**R:** A nota é marcada como "✅ Convertido" e fica cinza (histórico).

### P: Posso deletar notas convertidas?
**R:** ✅ SIM! Clique no 🗑️ em qualquer nota.

### P: As notas vão para backup?
**R:** ✅ SIM! Incluídas no export (JSON e Excel).
