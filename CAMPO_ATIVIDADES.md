# 📋 Campo de Atividades Semanais - Guia Completo

## 🎯 O que é o Campo de Atividades?

O **Campo de Atividades da Semana** é um campo livre onde você descreve tudo que fez durante a semana. O sistema analisa automaticamente o texto e **relaciona suas atividades com suas metas**, gerando um relatório profissional para seu gestor.

## ✨ Como Funciona?

### 1. Você Escreve Livremente

No campo "📋 Atividades da Semana", você descreve suas atividades de forma natural:

```
• Participei da reunião semanal do projeto Tax One SAP com time internacional
• Atuei no desenvolvimento do Tax Calendar para América Latina - implementei validações de CFOP
• Criei documentação técnica sobre integração SAP S/4HANA no Confluence
• Desenvolvi script em Python para automatizar extração de dados fiscais (iniciativa de IA)
• Participei ativamente da daily com sugestões de melhorias no processo
• Dei suporte ao colega Wilson na resolução de bug crítico do DPSP
• Estudei curso de inglês avançado para projetos internacionais
• Revisei e aprovei 3 pull requests no repositório do time
```

### 2. Sistema Analisa Automaticamente

O sistema identifica **palavras-chave** no seu texto e relaciona com suas metas:

#### 🔍 Palavras-Chave Monitoradas:

**❤️ Customer Experience (Parceiro Confiável)**
- cliente, customer, suporte, atendimento, feedback
- qualidade, excelência, revisão
- reunião com cliente

**🤖 AI Solutions (Corrida da IA)**
- ia, ai, inteligência artificial
- automação, script, machine learning
- inovação, otimização, melhoria

**💰 Finance + People**
- desenvolveu, aprendeu, estudei
- curso, treinamento, capacitação
- mentoria, ensinar, compartilhar conhecimento
- ajudei, suporte ao colega

**🔄 Internal - Reimagine with AI**
- processo, fluxo, metodologia
- eficiência, produtividade
- documentação, confluence, wiki, manual

**🎯 Transformação da IA**
- transformação, digital, modernização

**🚀 Metas de Carreira**
- inglês, english, internacional
- tax calendar, calendário fiscal, latam
- tax one, sap, s/4hana

### 3. Gera Relatório Inteligente

O PDF gerado automaticamente mostra:

1. **Suas atividades completas** (o que você escreveu)
2. **Alinhamento com metas** (como suas atividades contribuem para cada meta)
3. **Conquistas, entregas, aprendizados**
4. **Desafios e próximos passos**

## 💡 Dicas para Escrever Atividades Eficazes

### ✅ FAÇA:

1. **Seja Específico**
   - ❌ "Trabalhei no projeto"
   - ✅ "Implementei validações de CFOP no módulo Tax Calendar"

2. **Use Números**
   - ❌ "Ajudei colegas"
   - ✅ "Dei suporte a 3 colegas na resolução de bugs"

3. **Mencione Projetos/Tecnologias**
   - ❌ "Programei"
   - ✅ "Desenvolvi script em Python para automação de relatórios fiscais"

4. **Inclua Iniciativas de IA**
   - ✅ "Criei automação com IA para extração de dados"
   - ✅ "Propus uso de machine learning para classificação"

5. **Destaque Colaboração**
   - ✅ "Participei ativamente da daily com 3 sugestões implementadas"
   - ✅ "Compartilhei conhecimento sobre SAP em workshop interno"

6. **Mencione Documentação**
   - ✅ "Criei documentação técnica no Confluence sobre integração"
   - ✅ "Atualizei wiki do time com processo de deploy"

### ❌ EVITE:

- Descrições genéricas ("trabalhei", "fiz coisas")
- Falta de contexto ("reunião" - qual reunião?)
- Omitir resultados ("tentei fazer" - conseguiu?)

## 🚀 Como Usar Toda Sexta-Feira

### Passo a Passo Recomendado:

1. **Reserve 15-20 minutos** no final da tarde de sexta

2. **Revise sua semana:**
   - Confira seu calendário (reuniões)
   - Veja seus commits no Git (desenvolvimento)
   - Cheque tickets/Jira (entregas)
   - Revise e-mails (interações importantes)

3. **Escreva no campo de Atividades:**
   - Liste TUDO que fez
   - Seja específico e quantitativo
   - Use palavras-chave das metas

4. **Preencha os outros campos:**
   - Conquistas (resultados positivos)
   - Entregas (o que completou)
   - Aprendizados (o que aprendeu)
   - Desafios (obstáculos encontrados)
   - Próximos Passos (planos)

5. **Clique em "Gerar Relatório para Gestor"**
   - PDF é criado automaticamente
   - Revise o PDF
   - Envie ao seu gestor

## 🆘 Perguntas Frequentes

### "Preciso preencher TODOS os campos?"

O **campo de Atividades** é o mais importante. Os outros campos complementam, mas se estiver sem tempo, foque nas atividades.

### "E se eu não fizer nada relacionado às metas?"

Descreva o que fez mesmo assim! O sistema tenta encontrar conexões, mas o importante é ter registro do seu trabalho.

### "Posso editar um registro depois?"

Não diretamente, mas você pode criar um novo registro. Por isso, revise antes de salvar!

### "O relatório fica bom o suficiente para enviar?"

SIM! O PDF gerado é profissional, com visual Thomson Reuters, e pronto para envio ao gestor.

### "Quanto tempo leva para preencher?"

15-20 minutos se você fizer toda sexta. Se deixar acumular, pode levar 1 hora.
