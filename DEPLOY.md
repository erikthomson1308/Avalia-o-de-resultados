# 🌐 Como Compartilhar o Professional Tracker

Este guia mostra **3 formas gratuitas** de hospedar o Professional Tracker online e compartilhar com outros usuários.

---

## 📋 Opção 1: GitHub Pages (RECOMENDADO - Grátis e Fácil)

### ✅ Vantagens:
- 100% GRATUITO
- URL permanente (exemplo: `https://seu-usuario.github.io/professional-tracker`)
- Fácil de atualizar
- Profissional

### 📝 Passo a passo:

#### 1. Crie uma conta no GitHub
- Acesse: https://github.com/signup
- Crie sua conta gratuita

#### 2. Instale o GitHub Desktop (opcional, mas mais fácil)
- Download: https://desktop.github.com/
- Instale e faça login

#### 3. Crie um novo repositório
**Via GitHub.com:**
1. Clique no botão "+" no canto superior direito → "New repository"
2. Nome: `professional-tracker`
3. Marque "Public"
4. Marque "Add a README file"
5. Clique em "Create repository"

#### 4. Faça upload dos arquivos
**Via GitHub.com (mais fácil):**
1. Clique em "Add file" → "Upload files"
2. Arraste TODOS os arquivos da pasta `professional-tracker`:
   - `index.html`
   - `styles.css`
   - `app.js`
   - `README.md`
3. Clique em "Commit changes"

**Via GitHub Desktop:**
1. File → Add Local Repository
2. Escolha a pasta `professional-tracker`
3. Commit to main
4. Publish repository

#### 5. Ative o GitHub Pages
1. No seu repositório, clique em "Settings"
2. No menu lateral, clique em "Pages"
3. Em "Source", selecione "main" branch
4. Clique em "Save"
5. Aguarde 1-2 minutos

#### 6. Acesse seu site!
Seu site estará disponível em:
```
https://SEU-USUARIO.github.io/professional-tracker
```

---

## 📋 Opção 2: Netlify (Mais Rápido)

### ✅ Vantagens:
- GRATUITO
- Deploy em segundos
- URL customizável
- Drag & Drop (arrastar e soltar)

### 📝 Passo a passo:

#### 1. Crie uma conta
- Acesse: https://app.netlify.com/signup
- Pode usar sua conta do GitHub ou email

#### 2. Deploy via Drag & Drop
1. Após login, clique em "Add new site" → "Deploy manually"
2. **Arraste a pasta `professional-tracker` inteira** para a área de drop
3. Aguarde o upload (10-30 segundos)
4. Pronto! Seu site está no ar

#### 3. Customize a URL (opcional)
1. Clique em "Site settings"
2. Clique em "Change site name"
3. Escolha um nome (ex: `erik-professional-tracker`)
4. Seu site ficará: `https://erik-professional-tracker.netlify.app`

#### 4. Para atualizar
1. Na página do site, clique em "Deploys"
2. Arraste a pasta atualizada novamente

---

## 📋 Opção 3: Vercel (Profissional)

### ✅ Vantagens:
- GRATUITO
- Performance excelente
- URL customizável
- Integração com GitHub

### 📝 Passo a passo:

#### 1. Crie uma conta
- Acesse: https://vercel.com/signup
- Recomendo usar GitHub (integração automática)

#### 2. Deploy via Drag & Drop
1. Após login, clique em "Add New..." → "Project"
2. Clique em "Browse" ou arraste a pasta `professional-tracker`
3. Clique em "Deploy"
4. Aguarde 10-20 segundos

#### 3. Acesse seu site
URL será algo como: `https://professional-tracker-xyz.vercel.app`

---

## 🔗 Como Compartilhar com Outros Usuários

### Depois de fazer o deploy, você terá uma URL como:
```
https://seu-usuario.github.io/professional-tracker
ou
https://seu-app.netlify.app
ou
https://seu-app.vercel.app
```

### Para compartilhar:
1. **Copie a URL** do seu site
2. **Envie para seus colegas** via email, Teams, WhatsApp, etc.
3. Cada pessoa abrirá em seu próprio navegador
4. Os dados ficam salvos localmente (localStorage) em cada navegador

### ⚠️ IMPORTANTE:
- Cada usuário terá seus **próprios dados** (não compartilhados)
- Os dados ficam salvos no **navegador local** de cada pessoa
- Se quiser dados compartilhados entre usuários, precisaria de um backend/banco de dados

## 🎯 Qual escolher?

| Opção | Melhor Para | Dificuldade |
|-------|-------------|-------------|
| **GitHub Pages** | Compartilhar com muitas pessoas, URL permanente | ⭐⭐ Médio |
| **Netlify** | Deploy rápido, fácil de atualizar | ⭐ Fácil |
| **Vercel** | Performance máxima, profissional | ⭐ Fácil |

### 💡 Minha Recomendação:
1. **Se quer rapidez**: Use **Netlify** (5 minutos)
2. **Se quer permanência**: Use **GitHub Pages** (10 minutos)
3. **Se quer performance**: Use **Vercel** (5 minutos)

### Problemas comuns:

**Site não abre / erro 404**
- Aguarde 2-3 minutos após o deploy
- Limpe o cache do navegador (Ctrl+F5)
- Verifique se todos os arquivos foram enviados

**Quer atualizar o site**
- GitHub Pages: Faça novo commit dos arquivos
- Netlify: Arraste a pasta atualizada novamente
- Vercel: Arraste a pasta atualizada novamente
