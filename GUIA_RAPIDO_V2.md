## 1️⃣ BACKUP DOS SEUS DADOS (FAÇA AGORA!)

### Por que fazer backup?
⚠️ **IMPORTANTE**: Seus dados estão só no navegador. Se limpar cache = perde tudo!

### Como fazer (30 segundos):
```
1. Olhe no canto superior direito da tela
2. Clique no botão "💾 Backup"
3. Arquivo JSON será baixado automaticamente
4. Salve em local seguro (OneDrive, Google Drive, etc.)
```

### Quando fazer backup:
- ✅ AGORA (primeira vez)
- ✅ Toda sexta-feira (junto com registro semanal)
- ✅ Antes de limpar cache do navegador
- ✅ Antes de formatar o PC

---

## 2️⃣ ENCONTRAR REGISTROS ANTIGOS

### Problema: "Preciso encontrar aquela reunião que tive há 2 meses..."

### Solução (10 segundos):
```
1. Vá em "Registro Semanal"
2. Role até "Histórico de Registros"
3. Digite palavra-chave na busca: "Tax One SAP"
4. PRONTO! Todos os registros aparecem
```

### Filtros disponíveis:
- **📅 Por tempo**: Última semana | Mês | Trimestre | Ano
- **🎯 Por meta**: LOVED & TRUSTED | AI RACE | Finance & People | etc.
- **🔍 Por palavra**: Cliente | IA | Documentação | Reunião | etc.

### Dica PRO:
Combine filtros! Ex: "cliente" + "último mês" = todas as interações com clientes do mês

---

## 3️⃣ VER SEU PROGRESSO (DASHBOARD)

### O que você vê agora:

#### 📈 Gráfico de Evolução
- **O que é**: Linha mostrando suas últimas 8 semanas
- **Como ler**: Linha subindo = você está mais produtivo
- **Ação**: Se a linha cair, registre mais atividades!

#### 🎯 Gráfico de Pizza (Distribuição)
- **O que é**: Onde você está investindo tempo
- **Como ler**: Fatias grandes = metas que você mais trabalha
- **Ação**: Veja se alguma meta importante está pequena demais

#### 🔥 Contador de Streak
- **O que é**: Quantas semanas SEGUIDAS você registrou
- **Meta**: Chegar a 4+ semanas (fica verde!)
- **Ação**: Manter consistência

#### 📊 Mini Calendário
- **O que é**: Últimas 12 semanas visualizadas
- **Verde** = Registrou naquela semana ✅
- **Cinza** = Não registrou ❌
- **Ação**: Tente não deixar semanas cinza!

---

## 4️⃣ NOTIFICAÇÕES E LEMBRETES

### Banner Laranja no Topo
**Quando aparece**: Se você não registrar há mais de 7 dias

**O que fazer**: Clique em "Registre agora!" e preencha

### Toast (Canto Superior Direito)
**Quando aparece**: Ao fazer qualquer ação (salvar, exportar, etc.)

**Tipos**:
- ✅ Verde = Sucesso
- ❌ Vermelho = Erro
- ℹ️ Azul = Informação

### Badge "!" Laranja
**Quando aparece**: No botão "Registro Semanal" se você está atrasado

**O que fazer**: Clique e registre suas atividades

## 5️⃣ TROCAR TEMA CLARO/ESCURO

### Como trocar (1 clique):
```
1. Olhe no canto superior direito
2. Veja o ícone ☀️ ou 🌙
3. Clique UMA vez
4. Tema muda instantaneamente
```

### Quando usar cada tema:

**☀️ Tema Claro** (fundo branco)
- ✅ Durante o dia (escritório, home office)
- ✅ Ambiente bem iluminado
- ✅ Leitura de textos longos
- ✅ Apresentações/compartilhamento de tela

**🌙 Tema Escuro** (fundo verde escuro)
- ✅ À noite ou ambientes escuros
- ✅ Reduz cansaço visual
- ✅ Economia de bateria (telas OLED)
- ✅ Visual mais discreto

## 🎯 FLUXO DE TRABALHO SEMANAL

### Segunda-feira (2 minutos)
```
1. Abra o Professional Tracker
2. Olhe o Dashboard:
   - Veja seu streak
   - Confira gráficos de evolução
3. Se estiver atrasado, registre a semana anterior
```

### Durante a semana (conforme trabalha)
```
Mantenha um bloco de notas (ou Notes no celular) com:
- Reuniões importantes que participou
- Projetos que trabalhou
- Documentações criadas
- Iniciativas de IA/automação
- Interações com clientes
- Estudos/treinamentos
```

### Sexta-feira às 16h (10 minutos)
```
1. Vá em "Registro Semanal"
2. Copie suas anotações para o campo "Atividades da Semana"
3. Preencha conquistas e desafios
4. Clique "Salvar Registro"
5. Se precisar: Clique "Gerar Relatório para Gestor"
6. Faça backup: Clique "💾 Backup"
```

### Fim do mês (15 minutos)
```
1. Vá ao Dashboard
2. Analise os gráficos:
   - Evolução semanal subiu ou caiu?
   - Alguma meta está sendo negligenciada?
3. Use busca para revisar o mês todo
4. Gere relatório mensal se necessário
5. FAÇA BACKUP!
```

## 🆘 TROUBLESHOOTING RÁPIDO

### Problema: "Não vejo os novos gráficos no Dashboard"
**Solução**:
1. Pressione `Ctrl + Shift + R` (força refresh)
2. Ou: `Ctrl + F5`

### Problema: "Campo de busca não aparece"
**Solução**:
1. Verifique se está na seção "Registro Semanal"
2. Role até "Histórico de Registros"
3. O campo de busca está logo abaixo do título

### Problema: "Botão de backup não aparece"
**Solução**:
1. Olhe no HEADER (topo da página, canto direito)
2. Está junto com "📥 Importar", "📊 Excel", "📄 PDF"

### Problema: "Tema claro não funciona"
**Solução**:
1. Pressione `Ctrl + Shift + R` para refresh forçado
2. Clique no ícone ☀️ novamente

### Problema: "Importei dados e deu erro"
**Solução**:
1. Verifique se o arquivo é .json
2. Verifique se o arquivo foi exportado do Professional Tracker
3. Não edite o arquivo JSON manualmente

## 💡 DICAS PRO

### 🎯 Dica #1: Busca Inteligente
Use palavras-chave específicas:
- "reunião" + "cliente" = reuniões com clientes
- "documentação" + "SAP" = docs sobre SAP
- "IA" = todas as iniciativas de automação

### 🎯 Dica #2: Atalhos de Teclado
- `Ctrl + F`: Busca no navegador (complementa a busca do sistema)
- `Ctrl + Shift + R`: Refresh forçado
- `F12`: Console (para debug se algo der errado)

### 🎯 Dica #3: Organize Backups
Crie pasta no Google Drive/OneDrive:
```
📁 Professional Tracker Backups
  📄 backup-2026-08-04.json
  📄 backup-2026-08-11.json
  📄 backup-2026-08-18.json
  ...
```

### 🎯 Dica #4: Mantenha Streak
- Crie lembrete no Google Calendar: "Registro Semanal" toda sexta às 16h
- Meta: Nunca deixar passar de 7 dias
- Celebre quando chegar a 4, 8, 12 semanas!

### 🎯 Dica #5: Use Filtros para 1:1
Antes de reunião com gestor:
1. Filtre "último mês"
2. Veja tudo que fez
3. Gere PDF
4. Leve para a reunião
